# Sandbox Exchange with FastAPI

Тестовый двойник биржевого API для бэктестов торговых стратегий.

## Что это

Эмулятор биржи, который:
- отдаёт свечи из CSV по запросу
- принимает ордера и хранит позицию в памяти
- **не ждёт реального времени** — бот сам двигает свечи через `POST /next`
- API-совместим с реальной биржей — тот же код бота, что для реала

Это гибрид бэктеста и демо-счёта: скорость бэктеста + реализм API.

## Что это НЕ

- Не реальная биржа
- Не стакан, не матчинг ордеров, не ликвидность
- Не маржа, не ликвидации, не плечо
- Не WebSocket

Всё это — сознательно упрощено. Цель — проверить стратегию, а не построить биржу.

## Зачем

| Обычный бэктест | Sandbox Exchange |
|---|---|
| Бот и данные в одном процессе | Бот и «биржа» — разные процессы |
| Логика в цикле | Логика через HTTP/API |
| Нельзя потестить сетевой код | Тестируется весь сетевой слой |
| Нельзя подключиться с телефона | Можно — по Wi-Fi |
| Нельзя переиспользовать код | Тот же код, что для реала |
